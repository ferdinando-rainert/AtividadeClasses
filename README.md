# ☕ Estudos em Java

Repositório destinado ao **estudo e prática da linguagem Java**, reunindo exercícios, exemplos, conceitos e pequenos projetos desenvolvidos ao longo do aprendizado.

A ideia é utilizar este repositório como um **registro da evolução nos estudos**, mantendo os conteúdos organizados e servindo como material de consulta futura.

---

## 🎯 Objetivos

* Aprender e consolidar os fundamentos de Java;
* Praticar programação orientada a objetos;
* Desenvolver lógica de programação;
* Conhecer recursos e boas práticas da linguagem;
* Criar pequenos projetos para colocar os conceitos em prática;
* Registrar a evolução durante os estudos.

---
